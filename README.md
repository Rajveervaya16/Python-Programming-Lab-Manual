## ▶️ How to Run

1. Install **Python 3.10 or newer**.
2. Clone or download this repository.
   ```bash
   git clone https://github.com/Rajveervaya16/Python-Programming-Lab-Manual.git
   cd Python-Programming-Lab-Manual
   ```
3. Open the practical folder you want to run.
4. Run its program:
   ```bash
   python main.py
   ```

On some systems, use `python3 main.py` instead.

## 🧰 Dependencies & Environment Notes

Most practicals use Python's standard library. Some require extra packages, services, or internet/network access:

| Practicals | Requirements |
|---|---|
| 01–31, 47–59 | Primarily Python standard library |
| 32–35 | MySQL Server and `mysql-connector-python` |
| 36–41 | `pandas`, `matplotlib` |
| 42–45 | `python-whois` and internet access |
| 46 | `dnspython` and DNS/internet access |

Install the listed Python packages (if needed):

```bash
python -m pip install mysql-connector-python pandas matplotlib python-whois dnspython
```

**Configuration:** The MySQL examples use localhost, the `root` user, an empty password, and a database named `python` in their original code. Update the connection settings to match your own MySQL setup.

**Network exercises:** Some practicals use ping, DNS/WHOIS lookups, or local port scanning. Results depend on your operating system, network, firewall, and installed tools. Only test hosts and networks for which you have permission.
